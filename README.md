# 🚀 Overview

J.A.R.V.I.S is an AI-powered desktop voice assistant inspired by Iron Man.

It listens to voice commands, understands natural language, automates desktop tasks, controls Chrome, sends WhatsApp messages, searches the internet, answers questions using AI, and much more.

This project demonstrates Python programming, desktop automation, AI integration, speech recognition, and GUI development.

# ⚡ Installation

```bash
git clone https://github.com/yourusername/JARVIS-AI-Voice-Assistant.git

cd JARVIS-AI-Voice-Assistant

python -m venv .venv

.venv\Scripts\activate

pip install -r requirements.txt

python jarvis.py
```
